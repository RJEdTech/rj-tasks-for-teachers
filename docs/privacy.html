RJ Tasks for Teachers Privacy Policy

Effective October 22, 2026. RJ Tasks for Teachers is a Microsoft Edge extension made by Regis Jesuit High School Ed Tech for Regis Jesuit faculty and staff.

The short version

RJ Tasks for Teachers does not collect, store, sell or share personal information about you or your students. Everything it shows you stays in your browser, and it never changes anything in Canvas.

What RJ Tasks for Teachers reads

When you are signed in to Regis Jesuit's Canvas site (rjhs.instructure.com), RJ Tasks for Teachers uses your existing Canvas sign-in to read, for the classes you teach: your course list, assignments and their settings, assignment group weights, grading periods, submissions waiting to be graded, Canvas's Missing flags, and the names of your enrolled students. This is information you can already see in Canvas. It is used only to show you what's waiting to be graded, course setup problems, students with missing work, and what's due this week, on that same page.

What RJ Tasks for Teachers changes

Nothing. RJ Tasks for Teachers can only read from Canvas. It cannot create, edit, grade, publish or delete anything there.

What RJ Tasks for Teachers stores

In your browser's extension storage: your settings (the missing-work threshold, whether names start hidden, which classes to leave out, where the button appears), the ids of check-up items you chose to ignore, and the names and ids of the classes you teach, so the settings page can list them. If you sign in to Edge, Edge may sync your settings between your own devices. For the length of your browser session, the Canvas site also remembers whether you teach a current class and Canvas's to-grade count. RJ Tasks for Teachers never stores student names, student work or grades. These are held in memory only while the panel is open.

What RJ Tasks for Teachers sends

Nothing leaves your browser except requests to rjhs.instructure.com, the Canvas site you are already using. RJ Tasks for Teachers has no servers, no analytics, no advertising, no tracking and no third-party services, and it runs no code downloaded from the internet. It does nothing on any other website.

Browser permissions

RJ Tasks for Teachers asks for one permission, "storage," to save your settings. It runs only on pages at rjhs.instructure.com.

Student information

RJ Tasks for Teachers is provided by Regis Jesuit to its faculty and staff as part of the school's Canvas learning environment. It shows a teacher only information about students in that teacher's own classes, which the teacher can already see in Canvas. Student names are hidden by default until the teacher chooses to show them. The "Copy list" button puts a list of names and missing assignments on the teacher's own clipboard, only when the teacher clicks it.

Bug reports and feature requests

If you use the RJ Tasks for Teachers bug report and feature request form, your response goes to Regis Jesuit Ed Tech through Microsoft Forms, which requires an RJ sign-in and records your name so Ed Tech can follow up. That form is separate from the extension. Please don't include student names or grades in it.

Changes and contact

If this policy changes, the new version will be posted on this page with a new effective date. Questions: submit a Regis Jesuit Help Desk ticket or use the form above.
